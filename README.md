# Pusheen

A girl who lives in a doodled garden under Mount Fuji, inside your phone.

- Website: https://t4rjpeg.github.io/PUSHEEN/
- App: Actions → **Build Pusheen APK** → Run workflow, then download `Pusheen.apk` from Releases.
- Her brain: add an OpenRouter or Anthropic key in Settings (it stays on your device).

Files: `index.html` (page), `sprites.js` (her drawings, rig and voice), `scene.js` (garden), `core.js` (body and physics), `brain.js` (personality, missions, memory), `ui.js` (interface), `boot.js` (start-up).
